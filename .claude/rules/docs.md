# Docs

- English only. Short, factual, tables over prose. No duplicated content: link instead.
- `docs/product.md` = what and why; `docs/architecture.md` = how; `docs/plan.md` = current phase and status; `docs/adr/` = decisions (never edit an accepted ADR's decision; supersede it with a new ADR).
- Plan items in `docs/plan.md` always have **Done when** (a checkable criterion) and **Out of scope**. Tick an item in the same change that completes it.
